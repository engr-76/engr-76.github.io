ENGR 76 / Project 2D

From your laptop to a phone.

Use your own completed Project 2c and 2d notebooks on both devices.

1. Save and transfer both notebooks

Finish and save your Project 2d cryptography notebook. Also save your completed Project 2c notebook with convolutional encoding, the trellis, Viterbi decoding and all Part 3 signal helpers. An incomplete notebook will not become Ready.

For an iPhone and a Mac, AirDrop both .ipynb files to the phone and save them in Files. Otherwise open Snapdrop on both devices on the same Wi-Fi, select the other device, send both files, and save the received files. If that service is unavailable on your network, use a file-transfer method you already use.

2. Open the hosted demo

Open Project 2d encrypted audio demo in a browser on each device. No terminal, local server or downloaded demo folder is needed. Tap each notebook picker and choose the matching saved notebook. Wait for both to say Ready. If loading fails, finish the named function, save the notebook, and select the updated file again.

3. Agree on settings

Enter the same password separately on each device. Start with 100 bits/s, a 2000 Hz carrier, and the 1500–2500 Hz bandpass filter. Use a short message such as “Hello!” and comfortable speaker volume.

4. Receive before you send

On the phone, tap Receive, allow microphone access and wait for “listening.” Then tap Send on the laptop. After the entire tone has finished, tap Stop & decode on the phone. Cancel stops an operation and releases the microphone. Recording also stops after 20 seconds.

5. Compare the recovered bytes

The phone uses its own uploaded Project 2c functions to recover the nonce and ciphertext from sound, then its Project 2d decrypt function to recover the message. Compare the text or hexadecimal bytes with the original. Channel errors may remain, and this cipher cannot verify the password or detect tampering.

After sending or receiving, open the optional experiment panel. Try another password, or use the correct password and flip a ciphertext bit. These experiments reuse the last packet locally; they do not send another tone.

6. Share feedback

Trying the live audio demo and providing feedback in the reflection survey are required. If a technical problem prevents completion, describe what you tried and what went wrong; a successful transmission is not required.
